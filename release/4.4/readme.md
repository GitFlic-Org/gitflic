# 4.4.0 Что нового:

### Добавили

+ Репозитории реестров (Self-Hosted Enterprise)
+ Мультизадачность агентов
+ Новые страницы авторизации
+ Временные метки в логах задач конвейера
+ Предопределенную переменную CI_PROJECT_NAMESPACE
+ REST-API метод для получения списка пользователей проектов, команд и компаний
+ Мониторинг, метрики агентов, подключение Grafana
+ Дополнительные вкладки команд и компаний на странице пользователя в админ-панели

### Исправили

+ Верстку формы редактирования/создания файла на разрешении 768-992px
+ Описание полей на странице интеграции с Jira
+ Отображение количества скачиваний в реестре контейнеров
+ Ошибку при перезапуске задач конвейера
+ Переход со страницы при загрузке PyPi пакета при ручной загрузке
+ Политику отправки писем на почту пользователям, которые не приняли приглашение в проект
+ Политику работы динамических конвейеров. Внесли изменения во внешний вид на странице конвейеров, добавили новый лейбл
+ Порядок событий в вебхуках, интеграции с Telegram и уведомлениях на email
+ Проксирование пакетов NPM с зависимостями
+ Работу поездов слияния при использовании ручной задачи, приводящей к зависанию ЗнС
+ Создание зеркала через REST-API метод
+ Текст при блокировке аккаунта в Self-Hosted версиях
+ Чтение предзаполненных переменных при импорте CI-конфига по ссылке
