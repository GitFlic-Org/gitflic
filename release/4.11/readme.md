# 4.11.0 Что нового:

## Добавили:

+ Возможность отключения проверки patch-файла
+ Возможность подключать статические агенты в проектах на gitflic.ru
+ Импорт пользователей из LDAP (enterprise/ atlas)
+ Интеграция с трекером EvaProject
+ Настройку для управления автозапуска конвейера при создании тега
+ Параметры для управления частотой обновления и синхронизации пользователей из LDAP
+ Редирект на директорию, если нет файла при обращении по прямой ссылке


## Rest-Api:

+ Новый метод для добавления пользователя в проект от имени администратора (self-hosted)
+ Новый метод для импорта пользователей из LDAP(self-hosted)
+ Расширили методы получения списка пользователей в проекте, команде, компании. Теперь в ответе приходит информация о роли пользователей.
+ Расширили работу метода списка конвейеров проекта. Доступна фильтрация по branch и tag

+ Ошибку при попытке получить архив проекта по несуществующей ветке

+ Парсинг junit-отчета
