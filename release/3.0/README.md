## 3.0.0 

---

Обязательно прочитайте инструкцию по обновлению до версии 3.0.0 по [ссылке](https://docs.gitflic.space/setup/update_to_3.x.x), если планируете использовать сервис вместе с хранилищем S3.

Добавили:

+ CI/CD в облачной версии (beta)
+ Реестр пакетов в облачной версии (beta)
+ Реестр контейнеров (beta)
+ Масштабируемый координатор для агентов CI/CD
+ Работу с S3 сервером
+ Поддержку Яндекс.Облака
+ GPG-подписи коммитов
+ Новая политика зеркалирования (работа с приватными проектами, возможность создать push-зеркало)
+ Новые события в вебхуках и оповещениях в Telegram
+ Обновленный редактор с поддержкой md-формата
+ Новые методы API (создание команды, компании, методы для администратора сервиса)
+ Список файлов в запросах на слияние, которые ограничивают слияние
+ Поиск по имени пользователей для приглашения
+ Функцию выхода участников из проекта

Дополнительно добавили в Self-Hosted:

+ Git-Hooks
+ Новые административные настройки сервиса 
+ Push-правила (Self-Hosted Enterprise)

Доработали:

+ Подсветку кода в темной теме
+ Валидацию текстовых форм
+ Верстку сайта
