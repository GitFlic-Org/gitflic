## 2. General Provisions

The computer program GitFlic is designed to provide, store, and manage application source code repositories using the Git version control system. The Program's application domain is software development. The Program provides the following functions: storing the entire history of source code changes on its servers; checking for new code; changes recorded in a file or set of files allowing a return to a specific version of those files; the service allows storing code in public and private spaces. To manage repositories, the work of multiple participants with flexible access rights configuration for using the service is provided.

The Software is protected by the legislation of the Russian Federation from unauthorized use.

The Software is distributed through a network of authorized Partners.

The End User License Agreement (EULA) for using the Software is available for review on the website https://gitflic.ru/docs/license-sh.

## 3. Licensing

### "On-Premises" Licensing Option

A solution for installation on the User's own Node. The product is designed for storing and working with code within the User's perimeter.

The number of Nodes on which the Software can be installed is unlimited.

The licensing model depends on the selected Software edition.

### "Enterprise Standard" Edition

The License provides access to the Software installed on a Node. The number of required Licenses depends on the number of accounts to which the User's Employees using the Software must have access. The User must purchase a number of Licenses that corresponds to the total number of accounts of Employees using the Software.

The User has the ability to reassign accounts to new Employees independently.

The License under the "On-Premises" licensing option is provided in both commercial and free versions. The free License is provided by downloading the Software distribution from the Company's official website and is suitable for open-source projects and small teams, as well as for evaluation purposes.

The commercial License is suitable for teams of more than 5 people.

The minimum purchase threshold is 5 Licenses for the first order. The minimum order conditions do not apply in the case of an additional order when existing Licenses are present or when renewing Licenses for a new term.

### "Atlas" Edition

The number of required Licenses depends on the number of Nodes on which the Software will be installed. The User must purchase a number of Licenses that corresponds to the total number of Nodes on which the Software will be installed. 1 License may grant the right to use the Software on 1 or 3 Nodes, depending on the selected License.
